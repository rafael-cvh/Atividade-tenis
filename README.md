# Atividade-tenis

Projeto de uma loja de tênis masculinos feito para uma atividade de Front-end.

Sobre
A página mostra tênis masculinos usando dados da API pública DummyJSON.

Tecnologias
React, TypeScript, Vite, CSS

Funcionalidades
Lista de tênis masculinos.Mostra imagem, nome e preçoMostra carregamento. Página responsiva

API
DummyJSON:
https://dummyjson.com/products/category/mens-shoes
